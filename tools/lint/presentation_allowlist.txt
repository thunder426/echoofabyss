# Presentation seam allow-list (LIVE_SIM_UNIFICATION_PLAN.md 1.1, lint L3).
#
# Rules code (CombatHandlers, HardcodedEffects, RelicEffects, EffectResolver,
# ConditionResolver, TargetResolver, CombatManager) reaches gameplay data only
# through a typed CombatState. It may touch the combat shell in two other ways,
# and only with the names listed here.
#
# [presenter] — presentation only. Called on `presenter` / `ctx.presenter`,
#   which is null in sim and tests, so every call is null-checked. Must be
#   declared on CombatScene. Nothing here may change gameplay state.
#
# [facade] — gameplay whose live body is still VFX-bound (awaits a projectile,
#   defers into a popup drain, plays a summon animation). Called on the facade
#   (`_fx`, `ctx.scene`, `scene`), which is the CombatScene in live and the
#   CombatState in sim, so the call reaches the scene's VFX-rich override live
#   and the pure body otherwise. Must be a `func` on BOTH CombatScene and
#   CombatState. Phase 3.0 (de-async) empties this section.
#
# One name per line; `#` starts a comment.
