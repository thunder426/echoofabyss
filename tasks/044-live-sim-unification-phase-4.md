## Summary

Phase 4 shipped in four commits (0.640–0.643). Every fight, live or sim or test, is now built by `CombatState.setup_combat(CombatConfig)` with one `CombatSetup.setup(state)`. SimState, SimTriggerSetup and TurnManager are deleted, EnemyAI became the stateless `EnemyTurnRunner`, and rules code holds no shell or presenter: the last UI calls became journal events. CombatScene lost its 102 forwarders and 38 delegates (3,400 → 1,931 lines), and lint gained L9 (no duck typing) and a working `--report-pairs`. The sim now gives the enemy ancient_frenzy's opening Pack Frenzy, which live already did, so F3 moved −3 to −19 points; every other batch row is byte-identical.
Follow-ups: 3.6 owner visual QA (task 043 still open); Phase 5 parity test and live smoke matrix, then 4.5 (the D6 file split); the F15 forced end of the player's turn is still issued by the presenter (the sim doesn't end the turn); ChoiceModal cancel; F3 may need retuning after the Pack Frenzy change.
